# PolyhedraQt — Qt 5 Widgets / C++11 / CMake

Учебное приложение для построения правильных многогранников и демонстрации матричных 3D-преобразований.

## Сборка через CMake

Требуются CMake 3.16 или новее, компилятор C++11 и Qt 5 с модулем Widgets (Qt 5.12+).

### Из командной строки

Из корневого каталога проекта выполните:

```bash
cmake -S . -B build
cmake --build build
```

Запуск:
- Linux: `./build/PolyhedraQt`
- Windows: `build\Debug\PolyhedraQt.exe` или `build\Release\PolyhedraQt.exe` — в зависимости от генератора.

Если CMake не находит Qt, укажите путь к каталогу установки Qt через `CMAKE_PREFIX_PATH`, например:

```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH="/path/to/Qt/5.15.2/gcc_64"
```

### В Qt Creator

Откройте `CMakeLists.txt` как проект, выберите комплект Qt 5 и выполните сборку.

## Возможности
- Тетраэдр, гексаэдр, октаэдр, икосаэдр, додекаэдр.
- Матрицы 4x4 в однородных координатах: перенос, повороты X/Y/Z, масштаб, отражение XY/XZ/YZ.
- Масштабирование и вращение относительно геометрического центра.
- Вращение вокруг произвольной прямой через две заданные точки.
- Переключение аксонометрической и перспективной проекций.
- Постоянные цвета граней без освещения и расчёта теней.

## Структура и зоны ответственности
- `geometry/`: Point3D, Polygon, Polyhedron, PolyhedronFactory — геометрическая модель и генерация тел.
- `math/`: Matrix4, Transformations, Projection — матричная математика и проекции.
- `render/`: PolyhedronWidget — только отображение модели средствами QPainter.
- `ui/`: MainWindow — элементы управления и связывание UI с публичными API модулей.
- `main.cpp`: запуск Qt-приложения.

## Предлагаемое разделение между тремя участниками
1. **Геометрия и тела:** только каталог `geometry/`. Ответственность — классы точки, грани и многогранника, генераторы пяти тел. Контракт: `Polyhedron` содержит `vertices`, `faces`, `center()`, `applyMatrix()`.
2. **Математика:** только каталог `math/`. Ответственность — матрица 4x4, композиция преобразований, произвольная ось, проекции. Контракт: `Matrix4`, `Transformations`, `Projection`.
3. **Интерфейс и отрисовка:** `ui/`, `render/`, `main.cpp`. Ответственность — элементы управления, отрисовка фиксированными цветами, обработка действий пользователя. Использует API первых двух модулей, не меняя их реализацию.

Для интеграции сначала согласовать заголовки `.h`; каждый участник меняет только закреплённые за ним каталоги. `Polyhedron.h` включает `Matrix4.h`, поэтому интерфейс матрицы следует зафиксировать до параллельной разработки.

## Примечания
- Матрицы используют столбец координат `p = (x,y,z,1)^T`; преобразования комбинируются слева направо по правилу `M * p`.
- Проекция применяется только при отрисовке, поэтому она не меняет геометрию модели.
- Произвольное вращение реализовано матрицей Родрига вокруг направления AB с переносом к точке A и обратно.
- Отрисовка выполняет сортировку граней по глубине и не вычисляет освещение, поэтому вращение не меняет назначенные цвета граней.

## Отображение сцены

В области визуализации отображаются координатные оси `x`, `y`, `z` как в аксонометрической, так и в перспективной проекции. Модель и оси автоматически вписываются в доступную область при изменении размера окна; единый масштаб по экранным X/Y сохраняет пропорции фигуры. Панель управления размещена в отдельной прокручиваемой области и не перекрывает модель.
